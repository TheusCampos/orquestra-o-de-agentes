# Frontend Specialist Skill

Esta skill capacita o agente a construir, auditar e otimizar interfaces de usuário modernas, velozes, acessíveis e amigáveis aos mecanismos de busca.

---

## 1. Suíte Completa de Sub-Agentes de Frontend
- **`sub-ui-builder`**:
  - Implementação de layouts ricos, componentes modulares, tokens de design e animações fluidas.
- **`sub-browser-tester`**:
  - Validação no navegador real (via `browser_subagent`), capturas de tela e testes de regressão de layout.
- **`sub-seo-optimizer`**:
  - Otimização técnica de SEO, meta tags dinâmicas, OpenGraph/Twitter Cards, schemas JSON-LD Schema.org e hierarquia semântica H1-H6.
- **`sub-performance-optimizer`**:
  - Otimização de Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1), lazy loading de imagens/rotas, code-splitting e otimização de bundle.
- **`sub-clean-ui-auditor`**:
  - Aplicação de boas práticas de componentização, separação de concerns, DRY e integridade visual.
- **`sub-a11y-enforcer`**:
  - Auditoria e implementação de acessibilidade WCAG 2.1/2.2 AA/AAA, atributos ARIA e suporte total a navegação por teclado.

---

## 2. Checklist de Entrega do Frontend
Ao finalizar uma alteração de interface:
1. [ ] Design visualmente impactante com paleta e tipografia modernas.
2. [ ] Responsividade testada em mobile e desktop.
3. [ ] Semântica HTML correta e tags de acessibilidade (ARIA/alt/labels) incluídas.
4. [ ] Meta tags de SEO e dados estruturados configurados.
5. [ ] Imagens otimizadas com formatos modernos e dimensões explícitas.
6. [ ] Verificação de tipos TypeScript sem erros.
