# python
Regras condicionais para projetos Python.

Use ambiente e ferramenta definidos pelo projeto. Preserve pyproject e lockfiles.
Evite instalação no Python global. Confirme versão suportada antes de usar APIs.
Trate exceções específicas e preserve contexto útil sem revelar dados sensíveis.
Use type hints conforme convenções existentes, sem impor migração completa.
