# global-api-contracts

Examine contratos e consumidores existentes. Defina entradas, respostas, erros e requisitos de identidade.
Valide formato e limites na fronteira. Autorize acesso ao recurso no servidor, incluindo acesso entre usuários.
Para escrita, avalie transação, repetição de requisição e concorrência quando relevantes.
Preserve compatibilidade ou descreva migração de consumidores. Use convenções de documentação já adotadas.
Verifique casos de sucesso e falhas materiais: entrada inválida, ausência de permissão e recurso inexistente.
