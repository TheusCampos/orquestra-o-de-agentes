# GSAP Skills

Esta skill fornece ao agente Frontend e Motion Designer os parâmetros para usar GSAP de forma consistente.

## Aplicação
- Use `gsap.to()` e `gsap.from()` para micro-interações.
- Use `ScrollTrigger` para animações amarradas ao scroll (paralaxe, revelação de texto, pinagem de seções).
- Sempre inclua o CDN: `<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js"></script>`
- Evite conflitos com o CSS vanilla garantindo que opacidade e transformações iniciais sejam tratadas pelo próprio GSAP.
