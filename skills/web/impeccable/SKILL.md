# Impeccable Install

Garante que o código entregue pelos desenvolvedores atenda a um padrão de altíssima qualidade visual e técnica (impecável).

## Regras
- Código HTML sempre semântico e livre de divs desnecessárias.
- Regras CSS padronizadas com variáveis.
- Verificação restrita de erros em console JS (Zero warnings).
- Performance em primeiro lugar (lazy loading para imagens).
