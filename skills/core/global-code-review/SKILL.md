# global-code-review

Leia o diff e siga os fluxos afetados até contratos e consumidores.
Procure falhas de lógica, estado, autorização, concorrência e compatibilidade pertinentes ao escopo.
Para cada achado informe gravidade, arquivo/linha, cenário concreto, impacto e evidência. Identifique inferências.
Evite comentários de estilo sem impacto demonstrável e problemas preexistentes não relacionados.
Informe checks consultados ou executados e limites. Ausência de achados não prova ausência de bugs.
