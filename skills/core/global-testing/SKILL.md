# global-testing

Parta do comportamento alterado e dos riscos, não da quantidade de linhas.
Use os comandos existentes e testes do fluxo. Mudanças de contrato precisam verificar consumidores relevantes.
Adicione testes para regressões, regras de negócio e limites com chance real de falha; evite espelhar a implementação.
Para interfaces, confirme fluxo e estados no navegador quando disponível. Para scripts de arquivos, teste preservação e conflitos em pasta descartável.
Relate comando, resultado e limitações. Não substitua testes reais por descrição de testes pretendidos.
Amplie checks somente se mudanças novas, falhas ou preocupações não resolvidas justificarem.
