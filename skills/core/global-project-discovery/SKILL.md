# global-project-discovery

Identifique raiz, instruções locais, manifesto, lockfiles, pontos de entrada e comandos documentados. Use busca direcionada; evite ler diretórios de dependências e segredos.
Mapeie o fluxo relevante à solicitação e as alterações existentes no Git quando disponível.
Não execute scripts de instalação automaticamente apenas para descobrir o projeto.
Retorne: stack com evidência, arquivos relevantes, comandos de validação, restrições e dúvidas que bloqueiam implementação. Em trabalho longo, registre somente fatos confirmados no contexto do projeto.
