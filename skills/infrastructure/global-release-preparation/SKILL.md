# global-release-preparation

Confirme destino e comandos do projeto. Execute checks adequados e gere artefatos reproduzíveis.
Verifique configuração de exemplo, segredos esperados, migrações e ordem de atualização.
Documente rollback ou recuperação e verificação pós-publicação.
Prepare o resultado concreto antes de solicitar autorização ainda necessária para o deploy real.
Não publique automaticamente quando o pedido apenas solicita preparação. Respeite autorização de publicação já dada para o destino.
